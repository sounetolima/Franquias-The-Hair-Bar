# Franquias The Hair Bar

Site da apresentação de franquias **The Hair Bar Escovaria** — versão web 100% fiel ao arquivo *2026 Apresentação Franquia THB.pdf*.

- 20 slides em alta resolução (WebP, até 4K) com texto acessível para leitores de tela e buscadores
- Navegação por rolagem, setas do teclado e modo apresentação em tela cheia (tecla **F**)
- Contatos clicáveis no último slide (site, Instagram, WhatsApp e e-mail)

Site estático, sem build: publicado no Netlify a partir da raiz do repositório.

## Versão 2026 (pasta `2026/`)

Apresentação comercial voltada a investidores: dados de mercado 2025 com fontes, formatos de unidade, simulador de resultado, suporte, processo e FAQ. Publicada como site separado no Netlify (diretório base `2026`).
